# [P0 · M2] Keep prompts out of process metadata and diagnostics

## Summary

Initial and delegated prompts may contain sensitive material. Transport prompt contents without placing them in child argv, inherited child environments, or dry-run diagnostics, while preserving exact bytes and exact-once behavior.

## Public scope

- Redact prompt and sensitive option values from dry-run output.
- Use an owner-only one-shot transport for the interactive kickoff prompt.
- Keep prompt content out of the RPC child's inherited environment.
- Move headless delegated prompts off argv using a transport proven compatible with the pinned Pi mode.
- Clean temporary transport artifacts on success, failure, cancellation, and reload.

## Acceptance criteria

- A synthetic sentinel appears in no child argv, inherited child environment, or diagnostic output.
- The intended receiver obtains the exact prompt once, including multiline/Unicode content.
- Reload never replays the original prompt.
- Temporary artifacts are private and cleaned.
- No private Pi patch or protocol extension is introduced.
- Full unit and integration gates pass.

## Verification

```bash
bash -n bin/sumocode.sh
pnpm exec tsc --noEmit && pnpm build
pnpm lint
pnpm test
pnpm test:integration
```

## Dependencies

Requires the credential-safe PTY harness and launcher option parsing plans. Internal milestone: M2. Exact evidence and transport details are intentionally omitted from this public issue.
