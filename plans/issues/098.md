# [P1 · M2] Harden visible-subagent task artifact handling

## Summary

Visible subagents exchange prompt, response, lifecycle, and steering data through private local artifacts. Strengthen that boundary so artifacts remain confined to one owner-only task directory and cannot be redirected through path replacement.

## Public scope

- Allocate and validate one canonical private task directory per child.
- Use exclusive, no-follow creation for new artifacts.
- Validate owner, mode, regular-file identity, and direct-child confinement before reads/writes/removal.
- Preserve atomic steering publication and truthful acknowledgement.
- Keep normal visible-subagent lifecycle and worktree preservation unchanged.

## Acceptance criteria

- Adversarial temporary-fixture path replacements fail closed.
- Valid private artifacts support prompt, steer, close, response, and exit flows.
- Existing files are never overwritten by an exclusive create.
- Timed-out ambiguous steering remains recoverable under the existing protocol.
- Unit and integration gates pass.

## Verification

```bash
pnpm exec tsc --noEmit && pnpm build
pnpm lint
pnpm test
pnpm test:integration
```

## Dependencies

Requires truthful steering acknowledgement behavior. Internal milestone: M2. Exact artifact layout and adversarial recipes are intentionally omitted from this public issue.
